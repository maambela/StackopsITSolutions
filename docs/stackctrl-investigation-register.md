## Next implementation decision

Use the production measurements to choose the first boundary to fix. If the tenant INSERT is the largest blocked command, design byte-bounded storage for frozen evidence with atomic publication and verified tenant-scoped readers. Use the production column sizes to decide whether canonical deduplication provides enough margin for a limited cohort. If schedule summaries also exceed the limit, design their audit storage separately so a successful snapshot cannot appear to have failed solely because its summary was too large.

Production access, deployment, storage format activation and irreversible changes remain operator decisions. The rollout and export procedure is in [SQL payload diagnostics release](stackctrl-sql-payload-release.md).
